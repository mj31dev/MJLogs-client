# UI Inspection & Verification Skill

## Overview
This skill outlines how to visually inspect, debug, and verify Desktop UI components in Compose Multiplatform.

## Verification Checklist
1. **Visual Hierarchy & Typography**:
   - Check font scaling, line height, padding consistency, and contrast ratios in dark mode.
2. **State & Interaction Testing**:
   - Verify hover states, selection highlights, active search filters, and clear actions.
3. **Window Resize Handling**:
   - Test layout responsiveness when resizing the main desktop window from minimum to full screen.
4. **Log List Performance**:
   - Confirm virtualized scroll smoothness when rendering thousands of log items.
