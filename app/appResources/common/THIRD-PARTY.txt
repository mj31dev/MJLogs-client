Tesseract and its recognition model  —  Apache License 2.0
--------------------------------------------------------------------------------

The automatic synchronization reads the clock a screen recording displays. It does so on this
machine, with no network involved: nothing about the recording or the logs leaves the computer.

This application bundles the Tesseract OCR engine (https://github.com/tesseract-ocr/tesseract),
version 5.5.2, in the build published by the JavaCPP Presets project as
org.bytedeco:tesseract:5.5.2-1.5.13, under the Apache License 2.0, whose text is distributed with
this application as LICENSE.txt.

It also bundles the English recognition model eng.traineddata, taken from
https://github.com/tesseract-ocr/tessdata_best and likewise licensed under the Apache License 2.0.
It sits beside this notice, in the tessdata folder.
